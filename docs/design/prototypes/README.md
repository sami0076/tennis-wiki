# Prototypes

Self-contained HTML that a page was built to match. Each file's header says what in it is
authoritative (a sequence, its timings, a board's design, the copy) and what is placeholder
(rosters, numbers, the script itself). They are drawn in the visual world of their day, so
the materials are translated into `DESIGN.md` when a page is built; the structure, the
beats and the words are kept.

- `simulator.html`: the simulator's staged reveal, the scorelines, and one match watched
  game by game. Built on the site in September 2026.
